# About

I'm **Nokubonga Nkuna**, a CompTIA Network+ certified IT Technician based in Pretoria,
Gauteng, with a Diploma in IT (Networking & Cybersecurity) from Tshwane University
of Technology.

I'm currently in IT Systems Support at Dynamic DNA, working with servers and
client-server networks. Before that, as an IT Support Intern at TUT, I closed 30+
helpdesk tickets a day for more than 4,000 users, looked after 2,000+ workstations,
and was named Top User Service IT Intern 2025/26. I've also worked as a Mainframe
Intern (IBM z/OS) and spent three years mentoring ICT students.

I write this blog to:

- write down fixes so I (and you) can solve them faster next time
- explain networking, support and security topics in plain language
- share what I'm learning as I grow towards systems and security work

You can see my projects, including a Java security log analyzer, on
[GitHub](https://github.com/{{ site.github_username }}) and my
